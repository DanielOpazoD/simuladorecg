# Disclose the observed limits of T-end assistance

The manual T-end proposal currently emphasizes internal agreement without exposing
the adverse reserved-cohort accuracy result beside the marker. This can suggest
more confidence than the measured accuracy supports.

Keep the algorithm, numerical output, confidence labels and QT/QTc unchanged.
Whenever a proposal exists, show a persistent concise notice that its accuracy
was insufficient. Put the already published cohort results in the existing
expandable evidence section: 40 previously reserved records, 41 high-agreement
endpoints, p95 error 32 ms and maximum 56 ms versus predeclared limits 30/50 ms.
This is method-level evaluation, not an error bar for the selected beat. These
records are now exposed, not a new holdout or external clinical validation.

Acceptance: notice remains visible with details collapsed, keyboard expansion
reveals the numerical result, changing lead preserves it, and absent proposals
remove it. Inspect actual desktop/mobile browser captures. No new data, training,
endpoint threshold, automatic measurement or educational module is introduced.
